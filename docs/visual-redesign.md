# 刊物版面與首頁編排

## 設計方向

健康生活內容站以文章標題、資料來源與欄目建立辨識。首頁用主打文章、編輯選讀、時間序列與專題目錄組織閱讀；不以全屏品牌宣傳、生活口號、等大卡片或裝飾圖示填滿頁面。

品牌保留森林綠、深藍與暖白。深藍呼應既有標誌，綠色用於欄目與閱讀入口，金色僅用於必要細節。標題沿用 Noto Serif TC，正文維持既有大字級。用欄線、比例與字級區分主次，不依賴浮層、陰影或膠囊元件。

## 首頁編排

- 主打依公開文章的 `featured` 與發布時間選出；沒有可用稿件時顯示真實空狀態。
- `src/data/editorial.ts` 的 `HOME_READING_ORDER` 決定側欄選讀，填穩定 slug；缺少或未公開的稿件自動忽略，再從公開池補足。
- 最新文章依實際發布日期排序；主打、側欄與最新區不重複放同篇。
- 閱讀專題遵循 sections 與文章清單的編輯順序，不以日期取代閱讀順序。
- 導覽分類與欄目篇數由公開文章推導，不寫假熱門、假瀏覽數或假更新紀錄。

手機版先顯示實際文章標題，再放圖片，讓讀者第一屏知道有哪些內容。導覽直接呈現文章分類；搜尋在頁首可達。列表與專題頁短標題之後直接接內容，不重複大型主視覺。內文保留鍵盤目錄、表格捲動、分享、資料來源與更正入口。

## 內容與圖片

不同文章依問題選擇形式：包裝核對清單、食物替換例子、觀念問答或紀錄工具，不強制同一種段落模板。引用真實資料，區分整理、推論與個人建議；團隊署名不代表醫事審閱。文章與來源的核對筆記見 `docs/editorial-source-notes.md`。

素材使用與生成提示見 `docs/visual-assets.md`。圖解解釋具體資訊；照片呈現文章涉及的食物與情境。不以未授權人物、假專家、假團隊照、假產品標示建立可信度。

## 驗收

執行一般階段與 `PUBLIC_SITE_STAGE=production` 的 `pnpm verify`。版面改動後實看桌面、手機首頁、列表、專題與文章；確認標題可見、圖解未裁切、無水平溢出、搜尋可回到實際文章。導覽或資料結構變更時執行 `pnpm verify:content` 驗證根目錄與子路徑部署。預覽維持 noindex 且不載 GA；真正上線依 `docs/release-runbook.md` 執行。
