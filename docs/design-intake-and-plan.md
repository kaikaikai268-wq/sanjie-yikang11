# 三傑益康網站｜資料填寫表與設計計畫

## 已確定的方向

網站以健康生活、飲食營養與保健品判讀為核心，主要服務替自己或家人查找資訊的成年人。主要路徑為首頁、文章、主題指南、關於三傑；搜尋、內容署名與網站說明作為輔助入口。

舊網站資訊是示範素材，不直接視為正式品牌資料。團隊的場地服務確實存在，但本輪退出內容網站架構；產品、企業採購、場地報價與合作品牌介紹也先退出。Writer 接線與現有文章改寫由業主安排。新 Logo 先看提案再決定；正式聯絡資料稍後提供。

我先完成頁面版型、圖像、圖示、閱讀方向切換、圖片放大、手機版與工程檢查。以下資料可以分批填寫；尚未提供的項目不以虛構資料補上，也不在網站出現設計備註。

## 照片交付規格

- 給原始 JPG／HEIC／PNG，長邊至少 2400 px；人像盡量 3000 px 以上。不要先加文字、濾鏡、邊框或拼成社群圖。
- 場景照橫式 3:2 與直式 4:5 各拍；人物、招牌、包裝周圍留出裁切空間。
- 人像用自然窗光與乾淨背景，整批光線與穿著方向一致；工作照保留真實互動，不必全部看鏡頭。
- 產品先拍可讀的正背面，再補使用情境。檢驗、人物、公司、活動、產品本體使用真實素材。
- 每批附檔名、日期、人物／地點、攝影者、授權、可否裁切及署名要求。未確認的欄位寫「待確認」。
- 活動人物需有公開使用許可；避免病歷、個資、未同意曝光的人物與敏感螢幕畫面。

建議依「品牌、團隊、工作場景、活動、商品、授權文件、對外資訊」分資料夾。可以只先給已經有的，不需要等整包齊全。

## 參考與素材製作

介面檢查參考 Vercel Web Interface Guidelines（https://vercel.com/design/guidelines）；本地功能圖示採 Lucide（https://github.com/lucide-icons/lucide），固定版本與授權在專案內保存。照片由內建 image_gen 製作，檔案與完整提示見 docs/design-image-prompts.json。圖形 Logo 候選稿為原創向量提案，尚未採用。

這些工具只處理部分工作；版面是否成立，仍以真實內容、閱讀順序、品牌一致性、可用性及跨裝置檢查為準。

版面參考：康健（https://www.commonhealth.com.tw/）以編輯內容、主題與讀者服務分工；MedlinePlus（https://medlineplus.gov/）提供明確主題分類與搜尋。本站取其內容導覽原則，依目前內容量設計，不套用完整商業服務或醫療百科架構。
