# 三傑益康網站設計與素材交付清單

本次範圍是品牌、頁面、圖片、圖示與閱讀體驗。Writer 接線與既有文章改寫由業主安排；購物網站暫緩。

## 設計定位提案

「幫家庭把營養與保健資訊看明白。」主要服務替自己或家人查找營養、保健品與生活資訊的成年人，尤其是負責家庭採買、照顧家人或第一次比較保健品的人。這是設計工作假設，尚非已確認的市場調查結論。

網站的第一個任務是讓訪客找到問題、讀懂內容、繼續閱讀。第二個任務是讓人知道三傑是誰、提供什麼服務，以及怎麼聯絡。商品資訊作為獨立資料區，購物服務日後另接。

視覺採用現有標誌的墨藍、清綠與白色，統一標頭、字標、導覽、照片色調及功能圖示。標題保留中文刊物的閱讀感；品牌名稱使用清楚的黑體字標，避免與現有幾何標誌衝突。新 Logo 只製作提案，待業主確認後才替換。

## 拍攝交付方式

- 原始檔優先：JPG／HEIC／PNG，長邊至少 2400 px；人像盡量 3000 px 以上。不要先加文字、濾鏡、邊框或壓成社群小圖。
- 場景照每個場景同時拍橫式 3:2 與直式 4:5；不要把人物頭部、招牌、包裝貼滿邊緣，留出裁切空間。網站會另做手機裁切，不必自行排成拼圖。
- 人像用自然窗光、乾淨背景；團隊穿著與拍攝光線保持一致。拍工作照時保留真實動作，不必全部對鏡頭擺拍。
- 產品照先拍清楚正背面標示，再補生活使用場景；不要用生成圖補足不存在的產品細節。
- 活動照註明主講者和實際活動關係，避開不願曝光的參加者、病歷、個資、電腦畫面與未授權兒童肖像。
- 每個資料夾附一份簡單說明：檔名、拍攝日期、人物／地點、拍攝者、授權與可公開範圍；不確定的欄位標「待確認」。
- 可分批交付，不需要等所有資料齊全。優先是品牌與聯絡確認，再來團隊、場域、活動與產品更新。

建議資料夾：`01_品牌`、`02_團隊與顧問`、`03_公司與工作場景`、`04_活動與合作`、`05_產品原圖與規格`、`06_檢驗認證`、`07_對外資訊確認`。請告知實際路徑或提供可存取的資料夾。

## 我負責製作

- 品牌：標頭／頁尾的標誌組合、配色與字體整合；可縮放的新 Logo 候選稿與縮小尺寸檢視。取得原始檔或新稿獲准後再製作正式橫式、直式、單色及 favicon。
- 圖像：日常飲食與包裝閱讀情境圖、專題入口配圖、必要的原創圖解；逐張保留來源與用途，生成圖片標示為示意。
- 圖示：搜尋、前往閱讀、外部連結、飲食、標示、作息、分享、複製，採同一套線條與尺寸，保留文字標籤與授權。
- 互動：首頁閱讀方向切換，支援鍵盤、焦點、觸控及無 JavaScript 的普通連結；既有搜尋、分享、文章目錄繼續使用。
- 響應式：手機標頭不藏 Logo；大圖、側欄、專題頁各自有合適裁切及圖片尺寸。減少動態效果偏好者不使用動畫。
- 編排：照片、資料圖、文字分工；不以重複三卡、浮動標籤、裝飾漸層、空泛口號填版面。不替內容增添虛構專業背書。

## 驗收原則

視覺檢查包含桌面與手機、圖片裁切、Logo 與字標關係、字級與對比。互動檢查包含鍵盤方向鍵切換、可見焦點、Tab 順序、無 JavaScript 閱讀、真實連結與錯誤狀態。圖片有 alt／尺寸、懶載入、響應式版本與來源。新 Logo 的同意與頁面工程驗收分開；未確認的新 Logo 不上正式站。

工程驗證使用本專案 `pnpm verify` 及正式環境檢查。通過工程檢查不代表業務資料、肖像授權或專業資格已獲確認。
