兩盒益生菌放在一起，一盒強調菌數，另一盒寫了很長的英文名稱。先別急著用數字排高低：把菌株、每份量、保存條件與有效日期抄在同一張表，才知道自己比較的是不是同一件事。

## 菌株名稱，是查研究的線索

[美國國家衛生研究院 ODS](https://ods.od.nih.gov/factsheets/Probiotics-Consumer/)說明，益生菌的名稱可分成屬、種與菌株。購買前，可以看看包裝是否只有一個通稱，或另列完整名稱與菌株代碼。代碼不是裝飾；想核對某篇研究時，它能幫忙辨認研究用的微生物與手上產品是否相符。

[NCCIH 也提醒](https://www.nccih.nih.gov/health/probiotics-usefulness-and-safety)，不同類型的益生菌可能有不同效果。看到某種菌的研究結果，不能直接推成所有益生菌、所有配方或所有使用目的都有一樣的表現。廠商若提到研究，可以接著問：哪個菌株？哪一群人？研究觀察的是什麼？

## 菌數與保存，要放在同一張表

先拍下包裝，再補齊這幾格：

| 核對項目 | 可以留下的資訊 |
| --- | --- |
| 身分 | 屬、種、菌株名稱或代碼 |
| 計算單位 | 菌數是每粒、每包，還是每份？ |
| 數值時間 | 標的是製造時，或有效期限內的菌數？ |
| 保存條件 | 常溫或冷藏？開封後有沒有另外提醒？ |
| 日期 | 有效日期是否清楚，自己預計何時用完？ |

ODS 指出，有些產品需要冷藏，有些可常溫保存；菌數也可能隨時間下降。這也是為什麼保存方式與數值所指的時間，不能從比較表裡刪掉。只留下包裝正面最大的數字，反而會漏掉使用時的重要條件。

## 把產品問題和生活問題分開整理

標籤能幫忙了解產品，卻不能單靠標籤判定自己是否需要補充。若想處理的是日常排便或飲食問題，可以同時整理吃了哪些食物、何時出現變化；不要把每一個不舒服，都先歸因成「缺少某一種菌」。

這部分可接著看[膳食纖維的食物選擇](/articles/fiber-food-diary/)。比較產品基礎欄位時，則回到[保健品包裝閱讀清單](/articles/supplement-label-checklist/)逐項核對。若有嚴重疾病或免疫功能相關問題，NCCIH 建議先和醫療人員討論益生菌的使用，不用網路上的通用排名代替個別判斷。
